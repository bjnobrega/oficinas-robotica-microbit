# Recursos Complementares

Esta pasta reúne materiais adicionais para apoiar a implementação das oficinas de Robótica Educacional com BBC Micro:bit.

## Conteúdo

* Sugestões de atividades
* Materiais de apoio ao professor
* Referências bibliográficas
* Leituras complementares
* Desafios e extensões das oficinas

Os recursos aqui disponibilizados podem ser utilizados de forma independente ou em conjunto com as oficinas.
